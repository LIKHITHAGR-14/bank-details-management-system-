# Bank-details-management-system-
A Java-based desktop application designed to manage customer bank account information and perform basic banking operations. The system provides an easy-to-use interface for managing account details and carrying out transactions.

Key Features
Create and manage customer bank accounts
View customer and account details
Deposit and withdraw money
Check account balance
Manage banking records efficiently
Store and retrieve data from a MySQL database
Technologies Used
Java
Java Swing
JDBC
MySQL
Project Highlights
Developed a graphical user interface using Java Swing
Connected the Java application to MySQL using JDBC
Implemented database operations for managing customer and account information
Applied CRUD operations for effective data management
